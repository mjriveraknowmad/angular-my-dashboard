# MyDashboard
Este proyecto es de carácter educativo, del curso de angular de Fernando Herrera: https://www.udemy.com/course/angular-fernando-herrera.
En este caso, el proyecto es para el repaso de las características nuevas de Angular.

## Generar nuevo componente mediante cli
`ng g @schematics/angular:component dashboard/dashboard --skip-selector --inline-style --skip-tests`

## Comandos Dev

1. Clonar el proyecto
2. Instalar dependencias ```npm install```
3. Ejecutar el proyecto ```ng serve -o```
